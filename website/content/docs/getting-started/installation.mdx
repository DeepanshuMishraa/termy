---
title: Install
description: Download Termy for macOS, Linux, or Windows.
---

Get binaries from [/download](/download) or [GitHub Releases](https://github.com/lassejlv/termy/releases).

## macOS

Open the `.dmg` and drag Termy to `/Applications`.

If macOS blocks launch, see [Troubleshooting](/docs/getting-started/troubleshooting).

## Linux

Use the AppImage or `.tar.gz` from Releases.

## Windows

Run the `.msi` installer from Releases.

## From source

```bash
git clone https://github.com/lassejlv/termy
cd termy
cargo run --release -p termy
```

## First launch

| | |
| --- | --- |
| Theme | `termy` |
| Shell | your login shell (`$SHELL`) |
| Font | system monospace (Menlo on macOS, Consolas on Windows), 14px |
| Settings | `Cmd ,` (macOS) · `Ctrl ,` (Linux / Windows) |
| Command palette | `Cmd P` · `Ctrl P` |
